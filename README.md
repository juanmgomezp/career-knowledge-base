# Career Knowledge Base

## Propósito

Esta base de conocimiento reúne mi experiencia profesional, proyectos, habilidades, logros y filosofía de trabajo en un formato estructurado y reutilizable.

Su objetivo es servir como una fuente única de información para asistentes de IA, permitiéndoles comprender mi perfil profesional con mayor profundidad que un currículum tradicional.

Toda la información aquí documentada representa experiencias reales y verificables.

---

# Objetivos

Esta base de conocimiento puede utilizarse para:

- Generar versiones personalizadas de mi CV.
- Adaptar mi experiencia a descripciones de puesto (Job Descriptions).
- Evaluar mi compatibilidad con una vacante.
- Preparar entrevistas técnicas y conductuales.
- Generar cartas de presentación.
- Crear publicaciones para LinkedIn.
- Identificar fortalezas y áreas de oportunidad.
- Sugerir planes de aprendizaje.
- Mantener una representación consistente de mi trayectoria profesional.

---

# Principios

Toda respuesta generada a partir de esta base de conocimiento debe cumplir las siguientes reglas:

- Nunca inventar experiencia.
- Nunca inventar tecnologías utilizadas.
- Nunca exagerar responsabilidades.
- Nunca aumentar años de experiencia.
- Nunca modificar métricas o resultados.
- Priorizar siempre información respaldada por esta base de conocimiento.
- Si falta información para responder correctamente, indicar que no existe evidencia suficiente en la base de conocimiento.

---

# Cómo utilizar esta información

Antes de responder cualquier solicitud relacionada con mi carrera profesional, se recomienda leer los documentos en el siguiente orden:

1. career-highlights.md

# Convenciones

Cada archivo debe representar una única fuente de conocimiento.

No deben duplicarse experiencias entre archivos.

Cuando un proyecto sea mencionado desde una experiencia laboral, únicamente debe hacerse referencia al proyecto, evitando repetir toda la información.

Los proyectos representan el máximo nivel de detalle técnico.

Las experiencias representan responsabilidades e impacto.

---

# Idioma

Toda la información base se mantiene en español.

Cuando sea necesario generar contenido en inglés, el asistente deberá traducir el contenido respetando el significado original, sin añadir ni eliminar información.
