# Primeros años profesionales

## Propósito

Este documento describe las experiencias que dieron origen a mi perfil profesional antes de incorporarme a Ekasoft.

Aunque muchas de estas experiencias no están directamente relacionadas con mi trabajo actual, explican el desarrollo de habilidades que posteriormente resultaron fundamentales para desempeñarme en áreas de soporte técnico, automatización y mejora de procesos.

---

# Etapa 1 — Descubriendo el análisis de sistemas (2012–2013)

Mientras cursaba la universidad participé en un proyecto orientado al desarrollo de un sistema para administrar registros de usuarios y pagos.

Mi participación estuvo enfocada en el análisis funcional del sistema.

Durante esta etapa aprendí a:

- Analizar procesos de negocio.
- Identificar entidades y relaciones.
- Comprender reglas de negocio.
- Traducir necesidades operativas en requerimientos funcionales.

Aunque no participé en el desarrollo del software, esta experiencia despertó mi interés por comprender cómo los sistemas resuelven problemas reales.

---

# Etapa 2 — Primeros proyectos de desarrollo web (2013–2015)

Después de finalizar mis estudios comencé a desarrollar sitios web para pequeñas empresas.

Trabajé principalmente utilizando:

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery

Durante este periodo desarrollé aplicaciones web dinámicas desde cero, diseñando tanto la base de datos como la lógica del sistema y la interfaz de usuario.

Estos proyectos fortalecieron mi comprensión del ciclo completo de desarrollo de software.

---

# Etapa 3 — Soporte técnico e infraestructura (2014–2015)

Posteriormente trabajé brindando soporte técnico para equipos de cómputo e impresoras utilizados en puntos de venta.

Mis responsabilidades incluían:

- Diagnóstico de fallas.
- Mantenimiento preventivo.
- Mantenimiento correctivo.
- Atención directa a usuarios.

Esta etapa fortaleció mi capacidad para resolver problemas bajo presión y comunicar soluciones técnicas de manera clara.

---

# Etapa 4 — Desarrollo independiente

Durante este periodo continué desarrollando proyectos personales y sitios web para pequeñas empresas.

Estas experiencias me permitieron seguir practicando programación y diseño de soluciones mientras adquiría experiencia laboral en otras áreas.

---

# Etapa 5 — Experiencia administrativa y docencia (2016–2020)

Posteriormente trabajé en funciones administrativas dentro del sector educativo.

Aunque este puesto no estaba relacionado con tecnología, fortaleció habilidades que posteriormente serían muy valiosas:

- Organización.
- Comunicación.
- Documentación.
- Gestión de información.
- Atención a usuarios.

En 2020 también impartí clases universitarias en modalidad en línea sobre:

- Estadística.
- Sistemas Operativos.
- Fundamentos de Programación.

La docencia reforzó mi capacidad para explicar conceptos técnicos de forma sencilla y estructurada.

---

# Aprendizaje continuo

Durante este periodo mantuve un fuerte interés por el desarrollo de software.

Entre los proyectos personales más relevantes destacan:

- Desarrollo de un sistema para sincronizar reservaciones entre Booking y Airbnb mediante archivos iCalendar.
- Desarrollo utilizando Node.js, MongoDB y Vue.js.
- Implementación del sistema en AWS utilizando EC2 y S3.

Estas experiencias ampliaron significativamente mi perspectiva sobre arquitecturas web modernas.

---

# Preparó el camino para

Al incorporarme a Ekasoft ya contaba con experiencia en:

- Análisis de procesos.
- Desarrollo web.
- Bases de datos.
- Atención a usuarios.
- Resolución de problemas.
- Comunicación técnica.

Esta combinación de habilidades facilitó mi transición hacia la implementación de software empresarial y posteriormente hacia áreas de soporte técnico especializado, automatización y liderazgo de operaciones.
