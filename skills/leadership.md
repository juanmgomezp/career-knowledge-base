# Liderazgo Técnico

## Resumen

Mi estilo de liderazgo se basa en eliminar obstáculos para que el equipo pueda concentrarse en resolver problemas de alto valor.

Considero que un líder técnico debe seguir participando activamente en la operación para comprender los problemas reales del equipo.

---

# Principios

- Liderar con el ejemplo.
- Compartir conocimiento.
- Priorizar correctamente.
- Balancear cargas de trabajo.
- Documentar.
- Automatizar tareas repetitivas.

---

# Aprendizajes

Delegar no significa trabajar menos.

Significa distribuir inteligentemente el trabajo para garantizar la continuidad del servicio y permitir que cada integrante aporte el mayor valor posible.
