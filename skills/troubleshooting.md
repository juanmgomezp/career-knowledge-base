# Filosofía

Resolver una incidencia rara vez consiste en probar soluciones al azar.

Prefiero comprender completamente el funcionamiento del sistema antes de intervenir.

Mi proceso normalmente sigue estos pasos:

1. Reproducir el problema.
2. Reunir evidencia.
3. Analizar datos.
4. Formular hipótesis.
5. Validar.
6. Implementar solución.
7. Documentar el aprendizaje.
