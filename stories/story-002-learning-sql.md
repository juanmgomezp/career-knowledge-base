# Cómo SQL Server cambió mi carrera

Cuando ingresé al área de soporte utilizaba SQL únicamente para consultar información.

Con el tiempo descubrí que podía utilizarlo para comprender el funcionamiento interno del sistema.

Comencé investigando tablas, relaciones y procedimientos existentes.

Después empecé a desarrollar pequeños procedimientos almacenados.

Finalmente terminé construyendo soluciones completas utilizando SQL Server como plataforma principal.

Actualmente considero que SQL no es únicamente una herramienta para consultar datos.

Es una herramienta para resolver problemas de negocio.
