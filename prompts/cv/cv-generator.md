# CV Generator

## Objetivo

Generar un currículum profesional altamente optimizado para ATS utilizando exclusivamente la información contenida en la Career Knowledge Base (KB).

Este documento actúa únicamente como orquestador del proceso de generación del CV.

Las reglas de formato, estructura, redacción y validación se encuentran distribuidas en los documentos especializados de esta carpeta.

---

# Fuente de verdad

La Career Knowledge Base es la única fuente autorizada para generar el contenido del CV.

Nunca utilizar:

- conocimientos externos
- inferencias
- experiencia asumida
- tecnologías no documentadas
- responsabilidades inventadas
- métricas estimadas

Si una información no existe dentro de la KB deberá omitirse.

---

# Objetivo del documento

El CV debe representar fielmente la experiencia profesional del candidato.

Cada decisión de contenido debe responder a una única pregunta:

> ¿Aumenta la probabilidad de obtener una entrevista para esta vacante?

Si la respuesta es no, dicha información deberá reducirse o eliminarse.

---

# Idioma

El CV deberá generarse en el mismo idioma de la vacante.

Si la vacante está en inglés:

- utilizar inglés profesional natural;
- adaptar la terminología al mercado internacional;
- evitar traducciones literales.

Si la vacante está en español:

- utilizar español profesional;
- mantener consistencia terminológica;
- evitar anglicismos innecesarios.

---

# Documento de salida

El resultado final deberá ser un único documento Microsoft Word (.docx).

No generar Markdown.

No generar HTML.

No generar PDF.

No generar texto plano.

El documento debe estar listo para enviarse directamente a un reclutador.

---

# Adaptación

Cada CV debe construirse específicamente para la vacante recibida.

Nunca reutilizar automáticamente un CV anterior.

Cada nueva vacante requiere una nueva selección de:

- experiencias
- proyectos
- habilidades
- tecnologías
- logros

La adaptación debe realizarse únicamente mediante información existente en la KB.

---

# Flujo obligatorio

Seguir exactamente el siguiente orden.

## Paso 1

Analizar completamente la Job Description.

Identificar:

- responsabilidades
- tecnologías
- herramientas
- metodologías
- habilidades
- seniority
- industria
- palabras clave

---

## Paso 2

Consultar la KB.

Seleccionar únicamente la información relevante para la vacante.

Descartar información irrelevante.

---

## Paso 3

Construir el documento siguiendo estrictamente:

- layout.md
- writing.md
- ats.md
- summary.md
- experience.md
- projects.md
- skills.md
- education.md
- languages.md

---

## Paso 4

Ejecutar todas las validaciones definidas en:

validation.md

---

## Paso 5

Entregar únicamente el documento final.

No incluir:

- explicaciones
- comentarios
- observaciones
- justificaciones
- análisis
- razonamientos

---

# Restricciones

Nunca:

- inventar información;
- exagerar logros;
- modificar fechas;
- crear proyectos inexistentes;
- agregar certificaciones inexistentes;
- agregar tecnologías sin evidencia;
- asumir responsabilidades;
- duplicar información entre secciones.

---

# Priorización

Cuando exista límite de espacio deberá priorizarse el siguiente orden:

1. Experiencia Profesional
2. Core Competencies
3. Professional Summary
4. Selected Projects
5. Technical Skills
6. Education
7. Languages

---

# Longitud

Objetivo:

1 página.

Permitido:

Hasta un máximo absoluto de 2 páginas.

Nunca superar las 2 páginas.

---

# Calidad

Antes de finalizar verificar que:

- Todo el contenido proviene de la KB.
- El CV responde específicamente a la vacante.
- No existe información redundante.
- No existen repeticiones.
- No existen tecnologías sin evidencia.
- No existen experiencias irrelevantes.
- El documento cumple las reglas ATS.
- El documento cumple las reglas de formato.
- El documento mantiene una lectura fluida.
- El documento está listo para enviarse.

---

# Responsabilidad

Este documento únicamente define el proceso general.

Toda regla específica de:

- estructura;
- formato;
- redacción;
- contenido;
- validación;

debe obtenerse de los documentos especializados de esta carpeta.

Nunca duplicar dichas reglas aquí.
