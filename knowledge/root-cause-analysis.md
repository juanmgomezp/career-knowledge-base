# Root Cause Analysis

Cuando investigo una incidencia intento evitar resolver únicamente el síntoma.

Generalmente sigo un proceso similar:

1. Reproducir el problema.
2. Reunir evidencia.
3. Formular hipótesis.
4. Validar cada hipótesis.
5. Confirmar la causa raíz.
6. Diseñar una solución permanente.

Siempre que es posible documento la causa encontrada para evitar futuras incidencias similares.

En mi experiencia, invertir tiempo en comprender correctamente el problema suele ahorrar mucho más tiempo que implementar soluciones rápidas.
