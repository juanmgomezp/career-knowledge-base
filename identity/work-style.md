# Forma de trabajar

Me gusta comprender completamente un problema antes de comenzar a implementar una solución.

Generalmente sigo un proceso similar a este:

1. Comprender el problema.
2. Obtener evidencia.
3. Analizar datos.
4. Formular hipótesis.
5. Diseñar la solución.
6. Validar.
7. Documentar.

Prefiero invertir más tiempo en el análisis inicial para reducir el retrabajo posterior.
