# Logros Profesionales

Esta carpeta contiene los principales logros obtenidos a lo largo de mi carrera.

A diferencia de los proyectos, un logro representa un resultado alcanzado, independientemente de la solución utilizada para conseguirlo.

Los logros permiten a una IA seleccionar rápidamente evidencia cuantificable para fortalecer un CV, una entrevista o una carta de presentación.

Cada logro incluye:

- Contexto
- Problema
- Acción realizada
- Resultado
- Evidencia
- Competencias demostradas
