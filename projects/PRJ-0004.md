# Plataforma Centralizada de Encuestas y Analítica Comercial

# Contexto

El área Comercial realizaba periódicamente encuestas para conocer el nivel de satisfacción de los clientes, calcular el Net Promoter Score (NPS) y comprender las principales causas de cancelación del servicio.

El proceso dependía completamente de Microsoft Forms y hojas de cálculo, lo que implicaba generar manualmente las encuestas, enviar los enlaces, consolidar las respuestas y construir reportes de forma manual antes de presentarlos a Dirección.

Tras el éxito del proyecto Expediente Digital, el líder del área identificó la oportunidad de transformar este proceso y me invitó nuevamente a colaborar en el diseño de una solución que automatizara toda la operación utilizando la infraestructura disponible en la empresa.

Mientras él supervisaba la iniciativa y proporcionaba retroalimentación funcional, fui responsable del análisis, la arquitectura, el diseño de la lógica de negocio y el desarrollo completo de la solución.

---

# Problema

El proceso presentaba diversas limitaciones:

- Alta carga operativa para el área Comercial.
- Información distribuida entre múltiples herramientas.
- Consolidación manual de resultados.
- Riesgo de errores durante el análisis.
- Ausencia de una fuente centralizada para consultar resultados históricos.
- Dependencia de procesos manuales para generar indicadores ejecutivos.

Además, cualquier modificación en las preguntas implicaba reconstruir manualmente los formularios y adaptar los mecanismos de captura de información.

---

# Objetivo

Diseñar una plataforma centralizada que permitiera administrar distintos tipos de encuestas, automatizar su distribución y captura, consolidar la información en una única base de datos y proporcionar indicadores confiables para facilitar la toma de decisiones.

---

# Colaboración

El proyecto nació como una iniciativa del líder del área para mejorar los procesos del departamento Comercial.

Participé desde las primeras etapas del análisis funcional, proponiendo la arquitectura técnica, diseñando la lógica de negocio y desarrollando progresivamente la solución utilizando SQL Server, la plataforma RAD de la empresa y una aplicación web desarrollada en .NET.

Las decisiones importantes fueron revisadas periódicamente en conjunto para asegurar que la solución respondiera correctamente a las necesidades del negocio.

---

# Solución

## Plataforma centralizada de encuestas

Diseñé un sistema que permitió generar distintos tipos de encuestas desde una única plataforma integrada al Expediente Digital.

La solución reutilizó la información existente de clientes, corporativos y contactos, evitando duplicidad de datos y facilitando la administración del proceso.

Inicialmente el sistema soportó tres tipos distintos de encuestas.

---

## Plataforma web para clientes

Para simplificar la experiencia del usuario decidí utilizar enlaces públicos asociados a un identificador único generado desde SQL Server.

Cada encuesta se identificaba mediante un GUID, permitiendo validar automáticamente:

- Existencia de la encuesta.
- Vigencia.
- Estado de respuesta.
- Prevención de respuestas duplicadas.

El cliente únicamente debía acceder al enlace recibido y responder el formulario desde cualquier navegador, eliminando la necesidad de autenticación y reduciendo la fricción durante el proceso.

Posteriormente se incorporaron mecanismos adicionales de protección como validaciones antifalsificación de solicitudes y limitación de peticiones para fortalecer la seguridad del sistema.

---

## Dashboard analítico

Diseñé un dashboard integrado en la plataforma interna que permitía consultar en tiempo real indicadores como:

- Net Promoter Score (NPS).
- Nivel de satisfacción.
- Resultados por asesor.
- Resultados por categoría.
- Comentarios abiertos.
- Tendencias históricas.

Este dashboard sustituyó completamente el análisis manual realizado anteriormente mediante hojas de cálculo.

---

## Evolución hacia un sistema configurable

Durante la operación identifiqué que cada modificación en las preguntas requería actualizar el código fuente y publicar una nueva versión de la aplicación.

Con el objetivo de reducir el mantenimiento, rediseñé la arquitectura para convertir el sistema en una plataforma configurable.

Las preguntas, tipos de respuesta y opciones comenzaron a administrarse directamente desde la base de datos, permitiendo crear o modificar encuestas mediante configuración, sin necesidad de realizar cambios en el código del backend.

Esta evolución permitió que el sistema continuara operando durante más de un año sin requerir modificaciones en la aplicación.

---

# Decisiones de Diseño

## Reducir la fricción para el cliente

Se decidió utilizar enlaces públicos con identificadores únicos en lugar de requerir autenticación, priorizando la facilidad de uso para incrementar la tasa de respuesta de clientes con distintos niveles de conocimiento técnico.

---

## Diseñar pensando en el mantenimiento

En lugar de limitarse a resolver el problema inicial, el sistema evolucionó hacia una arquitectura configurable que redujo considerablemente el esfuerzo requerido para futuras modificaciones.

---
