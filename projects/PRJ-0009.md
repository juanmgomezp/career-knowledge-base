# Validación Funcional de API REST para Consulta de Comprobantes con Carta Porte

## Categoría

Proyecto de Validación Técnica

## Tipo de Proyecto

- API Validation
- Application Support
- Production Readiness
- Technical Validation

---

# Contexto

Durante mi etapa como Senior Support Engineer participé en la validación funcional de una API REST desarrollada a la medida para un cliente, cuyo propósito era consultar comprobantes CFDI con complemento Carta Porte.

El objetivo del proyecto era verificar el correcto funcionamiento de la API antes de su liberación a producción, validando tanto su comportamiento funcional como sus tiempos de respuesta en distintos ambientes del cliente.

---

# Objetivo

Validar que la API funcionara correctamente antes de su liberación a producción, verificando el flujo de autenticación, el consumo de los endpoints, la respuesta de las consultas y los tiempos de ejecución.

---

# Solución

## Comprensión de la API

Revisé la documentación técnica para comprender el proceso de autenticación, los endpoints disponibles, los parámetros requeridos y la estructura esperada de las respuestas.

---

## Validación mediante Postman

Utilicé Postman para consumir la API siguiendo el flujo definido en la documentación.

Primero realicé la autenticación mediante un endpoint POST para obtener el Bearer Token utilizado posteriormente en las solicitudes a los distintos endpoints.

Para facilitar las pruebas configuré variables dentro de Postman, permitiendo reutilizar el mismo token entre múltiples solicitudes y simplificando la validación en los diferentes ambientes del cliente.

---

## Validación Funcional

Ejecuté múltiples pruebas funcionales modificando los parámetros de consulta y ampliando los rangos de fechas para validar el comportamiento esperado de la API y confirmar que la información regresada fuera consistente.

Durante las pruebas registré periódicamente los tiempos de respuesta para cada ambiente del cliente.

---

## Análisis de Rendimiento

Al identificar tiempos de respuesta elevados durante algunas validaciones, ejecuté directamente el procedimiento almacenado utilizado por la API para comparar los tiempos obtenidos desde SQL Server con los tiempos observados en la API.

Los resultados fueron compartidos con el equipo de Desarrollo como evidencia para apoyar la investigación del origen del problema.

Una vez implementadas las optimizaciones correspondientes por el equipo de Desarrollo, continué validando la API para confirmar el correcto funcionamiento y la mejora en los tiempos de respuesta.

---

# Mi Contribución

Mi participación en este proyecto incluyó:

- Revisar la documentación técnica de la API.
- Consumir la API utilizando Postman.
- Validar el flujo de autenticación mediante Bearer Token.
- Ejecutar pruebas funcionales utilizando distintos parámetros de consulta.
- Registrar y monitorear tiempos de respuesta.
- Comparar los tiempos de ejecución entre la API y SQL Server para apoyar el análisis técnico.
- Documentar los resultados obtenidos para cada ambiente del cliente.
- Comunicar periódicamente los hallazgos al equipo de Desarrollo mediante Microsoft Teams.
- Validar nuevamente la API después de las optimizaciones implementadas.
