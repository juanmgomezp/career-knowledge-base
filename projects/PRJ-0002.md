# Automatización de Operaciones de Soporte mediante Funcionalidades de Autoservicio

## Categoría

Proyecto Interno de Support Operations

## Tipo de Proyecto

- Process Improvement
- Self-Service
- Support Operations
- Process Automation

---

# Contexto

Conforme aumentaba mi experiencia como Support Engineer comencé a dedicar parte de mi tiempo al análisis de los tickets atendidos por el equipo para identificar oportunidades de mejora.

Observé que una parte importante del trabajo operativo estaba relacionada con solicitudes repetitivas que podían ser ejecutadas directamente por los propios usuarios si el sistema ofrecía mecanismos seguros y correctamente validados.

Esto representaba una oportunidad para reducir la carga operativa del equipo de Soporte y mejorar la autonomía de los clientes.

---

# Problema

Diversas tareas administrativas requerían abrir un ticket de soporte a pesar de tratarse de operaciones simples.

Entre ellas destacaban:

- Ajustes administrativos menores.
- Reprocesamiento de documentos fiscales.
- Operaciones repetitivas que seguían siempre el mismo procedimiento.

Aunque técnicamente eran procesos sencillos, requerían tiempo del equipo de Soporte y generaban interrupciones constantes durante la operación diaria.

---

# Objetivo

Reducir el volumen de tickets recurrentes mediante funcionalidades de autoservicio que permitieran ejecutar determinadas operaciones de forma segura, controlada y auditada.

---

# Solución

## Identificación de oportunidades

Analicé el historial de tickets para identificar procesos repetitivos susceptibles de automatizarse sin comprometer la integridad del sistema.

---

## Diseño de funcionalidades

Desarrollé nuevas opciones dentro de la plataforma RAD utilizada por la empresa.

Cada funcionalidad ejecutaba procedimientos almacenados previamente diseñados en SQL Server e incorporaba:

- Validaciones de reglas de negocio.
- Restricciones de uso.
- Prevención de errores.
- Registro de auditoría.

---

## Capacitación y adopción

Además del desarrollo técnico elaboré manuales de usuario y realicé sesiones de capacitación para asegurar que los clientes utilizaran correctamente las nuevas funcionalidades y aprovecharan el autoservicio disponible.

---

# Mi Contribución

- Analizar tendencias de tickets.
- Identificar oportunidades de automatización.
- Diseñar funcionalidades de autoservicio.
- Desarrollar la lógica utilizando SQL Server y la plataforma RAD.
- Implementar controles para proteger la integridad de la información.
- Elaborar manuales de usuario.
- Capacitar usuarios finales.
- Validar el correcto funcionamiento de las nuevas opciones.

# Resultados

Las soluciones implementadas permitieron:

- Eliminar completamente determinadas categorías de tickets recurrentes.
- Reducir aproximadamente entre un 6% y un 8% el volumen mensual de solicitudes de soporte.
- Incrementar la autonomía de los usuarios.
- Liberar tiempo operativo del equipo para atender incidencias de mayor complejidad.
- Mejorar la experiencia del cliente mediante procesos más ágiles.
