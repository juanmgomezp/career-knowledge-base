# Aprendizaje Autodidacta

Gran parte de mis conocimientos han sido adquiridos de forma autodidacta.

Mi proceso normalmente consiste en:

- Comprender el problema.
- Investigar documentación oficial.
- Construir una solución.
- Cometer errores.
- Ajustar el diseño.
- Documentar el aprendizaje.

Este enfoque me permitió aprender tecnologías como:

- SQL Server avanzado
- Node.js
- MongoDB
- Vue
- AWS
- APIs REST
- Automatización
- Desarrollo asistido por IA
